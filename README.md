# finnrobert.no

Personlig blogg og fag-side om AI/KI — context engineering og praktisk agent-bruk, på norsk.

Bygget med [Astro](https://astro.build). Innhold skrives som markdown i `src/content/blogg/`.

```sh
npm install
npm run dev      # lokal utvikling på http://localhost:4321
npm run build    # statisk bygg til dist/
npm run preview  # forhåndsvis bygget
```

Se `CLAUDE.md` for struktur og konvensjoner.
